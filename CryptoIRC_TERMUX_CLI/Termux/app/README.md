# VaultForge Linux CLI

Run as a normal user (not sudo):

```bash
cd VaultForge/Linux
bash ./install_linux.sh
./start_linux.sh
```

This is the complete wallet + encrypted mesh console application. Choose **21 — MESH CHAT** to create a local account, connect to an existing relay, or host a private/WAN node.

Data is stored separately under `~/VaultForge`. Never put live wallet files, account databases or `node.secret` into a public repository.
